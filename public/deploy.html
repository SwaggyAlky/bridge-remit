Deploy Testnet Contracts with Your Wallet

Use a browser with MetaMask installed. Your private key stays in your wallet.

Before You Deploy

Use a dedicated test wallet funded with Sepolia test ETH. This flow supports chain ID 11155111 only. Sign four contract deployments and three corridor configurations: seven on-chain transactions in total. The connected wallet becomes the sole administrator.

When finished, download deployment.sepolia.json. It contains only public contract addresses, transaction hashes and ABIs. Upload it to the repository root to trigger a Render redeployment. The file contains no private keys. The backend RPC_URL must connect to Sepolia.

If deployment stops, successful contracts remain on the test chain. You can download the current progress; a complete configuration requires four addresses and three corridors. Restarting deploys a new set of contracts. Record successful transactions first to avoid unnecessary test gas costs.
