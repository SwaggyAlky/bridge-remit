# 用户手册

## 客户

连接钱包，确认网页网络与 MetaMask 网络一致，签署只用于登录的消息。新用户在管理与审计注册并等待管理员审核。领取测试币后，授权准确额度给托管合约；授权操作设定总额度，并不是追加额度。输入收款人地址、金额、通道和有效期。只有审核通过的客户可以发送和接收新汇款。核对网络费、平台费与实际领取 dUSD 数量，继续到钱包签名。

如果取消签名，草稿仍保存在数据库；到交易与凭证点击支付草稿重试。草稿的通道和期限取当前发起汇款表单设置，请先核对。已经创建的凭证不能重复付款。对账时用汇款编号和区块浏览器 hash，不用法币参考数替代真实到账资产。

收款人换钱包登录，打开交易与凭证领取。发送者可在领取前撤销，也可在到期后申请退款；到期后的收款签名会失败。双方可在到期前提出争议，之后等待管理员裁定。已经领取的汇款不能撤回。不要把争议当成自动退款保证。

## 企业付款

在企业批量付款粘贴最多 20 行 `收款地址,金额,备注`。所有收款人必须审核通过。先授权总金额，确认同一通道、24 小时有效期、总额和估算 gas。任意一笔验证失败时整批在链上回滚，不会只付其中一部分。数据库可能保留草稿，这不代表钱已经转出。没有 CSV 文件上传或后台自动代签功能。

## 管理员

部署钱包为管理员。设置客户、审计员或代理角色，再通过模拟审核；页面不接收身份证件。更新通道、参考汇率和不超过 500 基点的费率。暂停只限制新汇款。争议案件可以裁定给收款人或全额退给发送者，须在项目演示中解释裁定的中心化信任。提取平台费不会动用未完成汇款的本金。

## 审计员与代理

审计员可读取链上汇款状态和后端已核验回执，不可修改权限或放款。结算代理可对已完成汇款登记一次模拟出金凭证哈希；系统不据此自动认为银行已支付。真实回执可以在区块浏览器核验，后端只收录用户提交并成功核验的交易。

## 故障处理

审核未通过：联系管理员在应用中审核测试地址。授权不足：更新托管授权总额度。通道暂停或报价变化：刷新并重新核对。钱包拒绝：检查已保存草稿后重试。会话过期：重新连接和签名。RPC 暂时失败：不要依据报错直接重付，先在区块浏览器核验交易 hash。链上交易成功但回执保存失败时，资金状态已经改变，刷新状态而不是重新转账。切换钱包会清除旧会话并刷新页面。
