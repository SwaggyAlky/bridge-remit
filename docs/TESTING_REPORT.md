日期：2026-10-05。环境：Windows，Node.js 24.19.0，Solidity 0.8.30，Ganache 7.9.2，ethers 6.15.0。编译使用 optimizer 200、viaIR、Shanghai。数据库集成测试使用 Node SQLite 内存库。

执行 `pnpm build` 和 `pnpm test`。修复本地 SQL 参数绑定后，完整测试最终 **24/24 通过**：16 项合约测试、8 项 API 测试。源码中测试可直接重跑，原始日志在本地 data/test-run.txt，含本地测试环境信息，不发布该日志。

## 合约验证

## Gas 测量

以下为最终本地场景中各方法最后一次成功回执的 gasUsed，不是多次均值。不同余额、存储访问、分支和批次大小会改变 gas。

| 操作 | gasUsed |
|---|---:|
| create | 302,790 |
| batchCreate（2 笔） | 545,969 |
| claim | 57,345 |
| cancel | 49,647 |
| dispute | 36,112 |
| resolve 退款 | 53,036 |
| resolve 放款 | 60,599 |
| refundExpired | 49,731 |
| attest | 61,672 |
| withdrawFees | 60,398 |

两笔批次的每笔 gas 约 272,985，低于所记录单笔创建场景；场景状态不同，不能当作严格控制变量的性能结论。Bytecode 大小分别为 Registry 1,301、DemoUSD 1,979、CorridorBook 1,155、Escrow 6,536 bytes，均低于常用 EVM 合约大小限制。
