# 利益相关者验证与个人贡献

## 真实用户测试记录模板

邀请至少两类用户（例如务工家庭与 SME 财务）完成需求访谈或情景任务；不得收集不必要身份证件、银行信息或真实工资明细。

| 记录项 | 实际填写 |
|---|---|
| 日期、参与者匿名编号、用户类型、同意方式 | 待填 |
| 当前汇款方式与痛点（引述须获得同意） | 待填 |
| 任务：找到费用、识别实际领取资产、提交测试汇款 | 待填 |
| 成功与否、耗时、错误、求助次数 | 待填 |
| 能否区分参考法币金额与 dUSD | 待填 |
| 对撤销、争议、审核的理解与评分 | 待填 |
| 修改建议、已采纳改动、再次验证结果 | 待填 |

测量目标：用户能正确识别实际收款资产；报价到签名流程耗时；不重复付款的失败恢复成功率；角色隔离通过率。真实成本评估应包含入金、代币买卖价差、两次网络费、平台费与出金费用，本项目尚无这些完整实测。
